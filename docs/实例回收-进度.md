## 关键设计决策（已定）

1. 复用集中式 SA：avcodec 进程 `codecStubMap_` 已含整机所有实例，无需跨进程汇总。
2. 新增决策中心 `ReclaimManager`（`services/services/common/reclaim_manager/`）。
3. **接入回收机制**语义：只有注册了 `OH_VideoDecoder_RegisterReclaimCallback`（`InstanceInfo.isReclaimSubscribed=true`）的实例才走"回调通知 app"路径；未接入的由资源管控/ams 查杀处理。
4. 回收复用既有 `Release`/`NotifyMemoryRecycle` 链路 + `executor_.Commit` 异步释放，保证无泄漏。
5. `InstanceInfo` 扩展 `lastActiveTime`/`isReclaimSubscribed`/`reclaimValue`/`isReclaiming`。
6. 新增 `RECLAIM_*` 统计事件（`event_type.h` 的 `APP_BEHAVIORS` 主类目下）。
7. 候选选取：候选层级(硬解/安全硬解无区分→软解) → adj 低优先级 → 同 adj 取 reclaimValue 最大 → 本进程优先 → 优先选 isReclaimSubscribed。
